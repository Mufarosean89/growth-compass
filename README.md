# Growth Compass

Concept

 Audience segmentation

 Geographic analysis

 Time-series trends

 Release-performance analysis

 Collaboration analysis

 KPI calculations

 Forecasting where defensible

Application layer

 React/Next.js dashboard

 Interactive charts and filters

 REST API or FastAPI backend

 Authentication/demo accounts

 Responsive design

Decision layer

Instead of stopping at “streams increased 18%,” turn the analysis into recommendations:

Opportunity detected: Johannesburg shows sustained audience growth but relatively low event activity.
Recommended experiment: Test a Johannesburg-focused promotional campaign before the next release.
Expected signal: Compare engagement and streaming growth against comparable markets.

The unusual feature: the Artist Growth Simulator

Let someone change hypothetical decisions and see how the dashboard responds.

For example:

Scenario:
Release single → Target Johannesburg + Cape Town → 4-week campaign

The application produces a simulated projection of:

 audience growth

 engagement

 streaming activity

 potential event demand

Clearly label simulations as models/experiments rather than predictions of Nasty C's actual business performance.
